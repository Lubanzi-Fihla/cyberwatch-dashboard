# CyberWatch Security Dashboard

## Overview
CyberWatch is a Flask-based Network Security Monitoring Dashboard developed as part of the Codomax Cybersecurity Capstone Project.

## Features
- Device Status Monitoring
- Security Alert Tracking
- Failed Login Monitoring
- Security Event Dashboard
- SOC-style Interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- GitHub
